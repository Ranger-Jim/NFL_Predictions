# NFL Win Probability Model

A data mining project that predicts NFL game outcomes using team stats and rolling averages.

### 🔍 Overview
This notebook:
- Loads team and schedule data from `nflreadr`
- Merges and cleans weekly team statistics
- Trains a Logistic Regression classifier to predict wins/losses
- Evaluates model accuracy and visualizes performance
- Generates win probabilities for upcoming matchups

### ⚙️ Technologies
- Python
- pandas, scikit-learn, matplotlib, seaborn
- Jupyter Notebooks
- Git / GitHub
